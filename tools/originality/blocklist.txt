# Originality blocklist for tools/originality-check.sh. Maintained by the originality reviewer.
# Format:  kind | pattern | category | note
#   kind  en = Latin name, matched case-insensitively as a whole word; spaces, hyphens, apostrophes,
#              colons and dots in the name match each other or nothing ("Punch-Out" finds "Punchout").
#         he = Hebrew word or phrase, matched as a whole word, with up to two glued prefixes (ו ה ב כ ל מ ש ד).
#         re = raw Java regex, case-insensitive (use only when the two kinds above cannot express it).
#   category  game | studio | character | brand | platform | person
#   note      free text shown with the hit. A note containing "only a hit in player text" limits the entry to
#             player-facing strings and shipping documents (for names that are also everyday English words).
# Where each hit counts: player-facing strings and shipping documents use every entry; other code literals skip
# the "only a hit in player text" entries; comments and internal documents also skip the platform entries.
# Add a name whenever a brief, a reference or a review mentions a new work. Never remove one to make a hit
# go away: mark the line in the code with "originality-ok: <reason>" after the reviewer agrees instead.
# Common Hebrew words that are also brand names (דלק, פז, עלית, שרק, ספרינג, ויזה, דיסקונט) are left out on purpose:
# they would drown the report in false hits. Those are covered by the manual read in the release gate.
