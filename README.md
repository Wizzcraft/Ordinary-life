# אמא על הקו (Ordinary Life)

סימולטור חיים לאנדרואיד: עוברים לעיר הגדולה, שוכרים דירה זולה, מחפשים עבודה, ומנסים להחזיק מעמד עד שההורים באים לבקר. אמא מתקשרת כל שבוע.

זו גרסת סקיצה: כל הגרפיקה היא פוליגונים שמצוירים בקוד, בלי נכסים חיצוניים.

## מה יש עכשיו (שלב 1)

- בהתחלה בוחרים גבר או אישה ומקלידים שם, והמשחק פונה אליך בשם.
- מפת עיר במבט מלמעלה. לוחצים על בניין והדמות הולכת אליו בכבישים.
- שעון: שעת משחק היא 3 שניות, יום שלם קצת יותר מדקה. יש כפתור להרצת זמן.
- מדי אוכל, מים ואנרגיה, ותיק עם ארוחות ובקבוקים.
- דירה (שינה, מים מהברז), סופר, ומסעדה עם עבודה כטבח ומיני גיים.
- שכירות כל 10 ימים, שיחות מאמא, התעלפות וסוף משחק.
- אפשר לצאת בכל רגע: המשחק נשמר וחוזר בדיוק לאותה נקודה, גם באמצע הליכה, שינה או משמרת.
- בזמן עבודה המעסיק נותן אוכל ושתייה.
- בתוך תפריט של בניין ובתפריט הראשי הזמן עומד.
- שאר הבניינים (לימודים, קזינו, בר, מאפייה, תחנת דלק, סמטה) מסומנים "בקרוב".

## התקנה

כל push ל-`main` בונה APK ב-GitHub Actions ומפרסם אותו ב-Releases תחת התגית `latest`.
מורידים את `ima-al-hakav.apk` מהטלפון ומתקינים. גרסאות חדשות מתקינות מעל הקודמת ושומרות על המשחק.

## מבנה הקוד

- `app/src/main/java/com/wizzcraft/ima/core/` — כל המשחק, Java נקי בלי תלות באנדרואיד. מצייר דרך הממשק `Gfx`.
- `app/src/main/java/com/wizzcraft/ima/` — מעטפת אנדרואיד דקה: `MainActivity`, `GameView`, `AndroidGfx`.
- `tools/desktop/` — כלי בדיקה שמריץ את המשחק על מחשב, מצלם מסכים ומריץ בוט ובדיקת לחיצות אקראיות:

```
javac --release 17 -d tools/out/classes app/src/main/java/com/wizzcraft/ima/core/*.java tools/desktop/com/wizzcraft/ima/core/*.java
java -Djava.awt.headless=true -cp tools/out/classes com.wizzcraft.ima.core.Sim tools/out
```

רוב המספרים לכיוונון (מחירים, שכר, קצב רעב, אורך יום) נמצאים בראש `Game.java`.
